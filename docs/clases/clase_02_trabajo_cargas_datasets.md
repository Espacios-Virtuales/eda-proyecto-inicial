# 🌒 Clase 2 — Trabajo con cargas y datasets  
## 🜁 Laboratorio · Rama de exploración

---

## 🌿 Propósito de la sesión

En esta clase comenzamos a trabajar con datos reales dentro del proyecto.

No solo creamos estructura:  
ahora activamos el flujo de exploración.

Introducimos el concepto de **rama (branch)** como espacio de trabajo independiente.

---

## 🧭 Objetivos de aprendizaje

Al finalizar esta sesión podrás:

- Crear una rama en Git
- Trabajar de forma aislada sin afectar la base del proyecto
- Incorporar un dataset al repositorio
- Realizar una primera exploración de datos (EDA)
- Registrar tu trabajo con commits

---

## 🌊 Concepto clave

### 🔹 Rama (branch)

Una rama es:

- una línea de trabajo paralela  
- un espacio de exploración  
- una forma de probar sin romper el proyecto principal
