## 🌊 Conceptos clave

### 🔹 Repositorio

Un repositorio es:

- un espacio donde vive tu proyecto  
- una memoria de tu proceso  
- una línea de tiempo de decisiones  

---

### 🔹 Commit

Un commit es:

- un registro de cambio  
- una acción nombrada  
- una huella en el tiempo  

Ejemplo:

- "estructura inicial del proyecto"  
- "primer analisis exploratorio"

## 🧱 Estructura base del proyecto

```
neuronas-ev-lab-api/
 ├─ data/           # Acceso a datasets
 ├─ docs/           # Documentación de proyecto
 ├─ notebooks/      # Hojas trabjos
 ├─ src/            # Servicios
 ├─ LICENSE            
 └─ README.md   
```


Cada carpeta tiene un propósito:

- data → datos crudos  
- notebooks → exploración  
- src → lógica y funciones  
- outputs → resultados
