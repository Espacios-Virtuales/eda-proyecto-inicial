> “Este repositorio no es solo código.  
> Es memoria, práctica y conciencia en construcción.”

---

## 🧭 Propósito

Este proyecto nace como un espacio para:

- explorar datos
- comprender patrones
- construir pensamiento analítico
- registrar el proceso de aprendizaje

Aquí no solo se busca responder preguntas,  
sino aprender a formularlas.

---

## 🧱 Estructura del proyecto

```
eda-proyecto-inicial/
 ├─ data/           # Acceso a datasets
 ├─ docs/           # Documentación de proyecto
 ├─ notebooks/      # Hojas trabjos
 ├─ src/            # Servicios
 ├─ LICENSE            
 └─ README.md   
```

## 🜂 Primeros pasos

1. Crear estructura base  
2. Registrar primer commit  
3. Iniciar exploración de datos  
4. Documentar hallazgos  

---

## 🔁 Flujo de trabajo

- Cada cambio relevante se registra con un commit
- Los commits deben ser claros y descriptivos
- El README evoluciona junto al proyecto

Ejemplos de commits:

- `estructura inicial del proyecto`
- `primer analisis exploratorio`
- `limpieza de datos inicial`
